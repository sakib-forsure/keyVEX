## 2. Migration Plan (Firestore, SQLite, IndexedDB & Legacy Vaults)

1. **Automatic Metadata & Tombstone Migration**:
   - On next unlock, rekey, or Passkey reset, `Vault` automatically migrates `emailResetWrapped`/`Salt` to `accountResetWrapped`/`Salt`, strips legacy `recoveryWrapped`/`recoverySalt`, wraps device entropy under the non-extractable `CryptoKey` (`wrappedDeviceEntropy`), and prunes `meta.deletedEntries` while syncing tombstones to `/users/{uid}/tombstones/{entryId}`.
2. **Client-Side Authenticated Firestore Migration (`#runCanonicalFirestoreMigration`)**:
   - Compares local IndexedDB / Custom API entries against Cloud Firestore (`/users/{uid}/entries`) using stable `entry.id`, `vaultId`, `updatedAt`, and `ciphertextHash` (`SHA-256(iv:data)`), preserving any divergent records in `v6_conflicts` (`vault.getConflicts()`).
3. **Read-Back Verification**:
   - Uploads `meta` (`schemaVersion: 2`, `metaRev`) and missing encrypted entries to Cloud Firestore, then verifies that every entry decrypts with `this.#vk` before marking `canonicalMigrationVersion: 1`.
